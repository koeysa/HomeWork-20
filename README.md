Д/З  к 20-ой лекции. Массив целых чисел равен 10. Значения задаются 2-мя способами: 1) с клавиатуры; 2) генерируются случайные числа в заданном пользователем диапазоне. С клавиатуры вводится два числа - порядковые номера элементов массива, которые
необходимо суммировать. Нужно предусмотреть случаи, когда были введены не числа, и когда одно из чисел, или оба
больше размера массива.
